

Quiero crear una aplicación web fullstack moderna y profesional usando Next.js + Supabase + TailwindCSS.

# OBJETIVO GENERAL

Construir una plataforma de seguimiento de ofertas laborales donde cada usuario pueda:

- buscar ofertas automáticamente desde portales de empleo
- guardar ofertas manualmente
- administrar estados de postulaciones
- filtrar y buscar empleos
- llevar seguimiento personal de sus postulaciones

La aplicación debe ser escalable, moderna, responsive y preparada para producción.
